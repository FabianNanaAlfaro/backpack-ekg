## Repository-specific credit

This repository is maintained as a public engineering companion by Fabian A. Nana. It consolidates the recovered public firmware, makes the threshold-based BPM method explicit, fixes plotting and state-management defects, and adds portable tests and release checks. That description is intentionally narrower than a formal author-contribution statement.
